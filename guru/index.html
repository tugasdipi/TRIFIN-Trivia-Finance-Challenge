Kode nilai = kelas + tim + 8 skor + checksum

Interpretasi & Verifikasi

Nilai terbaik per Pos yang tersimpan akan masuk ke kode nilai. Jika belum tercatat, dekoder menampilkan “Belum dinilai”.
Pos 6: handbook sumber mencatat kemungkinan skor mentah tertinggi yang teramati 100 sementara pembagi 120. Uji kembali pada file game final bila ingin memastikan nilai maksimum efektif.
Pos 9: project dinilai terpisah. Penyelesaian asesmen di website bergantung pada konfirmasi siswa, sehingga guru tetap perlu mencocokkan dengan respons Google Form.
Keamanan: kunci pengacak kode nilai tertanam pada HTML. Untuk penilaian formal, jangan gunakan kode nilai sebagai satu-satunya bukti.

Dekoder Kode Nilai

Tempel kode nilai dari kelompok. Sistem akan membaca kelas, tim, skor Pos 1–8, dan rata-rata sementara secara lokal di browser.

Solusi Masalah

Gunakan bagian ini sebagai referensi cepat saat siswa mengalami kendala selama berpindah Pos atau menggunakan website.

Troubleshooting cepat
Periksa format. Gunakan TRF-{kelas tanpa strip}-{kode tim}, misalnya TRF-IXC-EUR. Jangan memakai spasi.
Cocokkan PIN dengan menu Data Tim, PIN & Rute. PIN tim bersifat tetap pada konfigurasi handbook ini.
Pastikan Pos sebelumnya dalam rute tim sudah diselesaikan. Setelah itu masukkan kode QR untuk Pos berikutnya sesuai tim.
Kemungkinan QR berasal dari tim atau Pos lain. Cocokkan empat digit dan format lengkap melalui menu Kode Akses QR.
Pos 1–8 harus seluruhnya tercatat selesai. Jika perlu pemeriksaan teknis, lihat progres pada browser siswa atau gunakan prosedur darurat pada menu Catatan Teknis.
Progres terikat pada perangkat dan browser. Menghapus data situs, memakai mode penyamaran, atau pindah perangkat dapat membuat progres tidak terbaca.
Minta siswa menyalin ulang melalui tombol “Salin kode”. Dekoder menolak kode yang salah panjang, berubah, atau checksum-nya tidak sesuai.
Periksa internet dan akses YouTube. Bila jaringan sekolah memblokir YouTube, guru dapat menayangkan video secara klasikal sebagai alternatif.
File permainan utama dapat sangat besar karena media base64. Gunakan perangkat dengan memori lebih lega, tutup aplikasi lain, atau pakai komputer/laptop bila HP tidak stabil.

Penyimpanan Progres

Ganti Perangkat

Session

Menutup tab dapat menghapus scope sesi sehingga siswa perlu login ulang.

Mode Samaran

Hindari incognito/private mode karena penyimpanan bisa hilang saat sesi selesai.

Hal yang Perlu Diverifikasi

  1. Folder Drive kelas yang masih placeholder harus diisi sebelum pelaksanaan.
  2. Uji pemetaan nama kelas login (IX-A–IX-J) dengan nama kelas pada Pos 9 (9A–9J).
  3. Uji satu kelompok dari login sampai Pos 9 pada perangkat yang akan dipakai.
  4. Jangan mengandalkan kode QR/PIN/kode nilai sebagai satu-satunya pengaman penilaian.
